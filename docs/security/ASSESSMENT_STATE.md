# Assessment state (public mirror)

The detailed security assessment record (red-team, blue-team and verification
reports) is kept in the private repository and is not published here.

Rules that still apply to anyone working in this repository:

- An implementing session cannot close its own findings. A separate verification
  session must confirm and close every fix.
- Do not report security problems in public issues. Email support@accountabul.com instead.
- Never commit credentials, `.env` files or real customer data.
